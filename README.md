# 🌿 Nature Sphere — Blog Website

Nature Sphere is a responsive blog website where users can create an account, log in, and manage their own blog posts.

The project includes user registration and login functionality along with complete post management features such as creating, editing, updating, and deleting posts.

## ✨ Features

### 👤 User Authentication
- User Registration
- User Login
- User Logout
- User information management

### 📝 Post Management
- Create new posts
- View posts
- Edit posts
- Update posts
- Delete posts
- Manage blog content

### 🎨 User Interface
- Clean and simple design
- Responsive layout
- Easy navigation
- Nature-focused blog theme

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
